How we keep these documents tamper-evident

Each document below is hashed, pinned to IPFS, and anchored to the Hedera Consensus Service — a public, independently timestamped ledger. This page queries that network directly, live, at load time; nothing below is read from any database this project maintains. The hash shown for each document is a unique digital fingerprint of its exact contents — change even a single character and the fingerprint changes completely. For a document's fingerprint and instructions to check it yourself, see the changelog.
