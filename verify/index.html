Verify

Independent proof that these documents are exactly what they claim to be.

This page currently points at Hedera testnet — a free practice network, not the permanent public record. Nothing shown below carries legal or evidentiary weight yet.

Each core document is hashed, pinned to IPFS, and anchored to the Hedera Consensus Service — a public, independently timestamped ledger. This page queries that network directly, live, at load time. Nothing below is read from any database this project maintains — you're seeing exactly what Hedera's own public mirror node reports.

The hash shown for each document below is a unique digital fingerprint of its exact contents. Change even a single character and the fingerprint changes completely — so if your copy's fingerprint matches the one shown here, you can be certain it's exactly what was published, unaltered.

How to check a document's fingerprint yourself

Download the PDF, then run this command in a terminal (Mac/Linux: shasum -a 256 filename.pdf, Windows: certutil -hashfile filename.pdf SHA256), and compare the result to the hash shown for that document. If they match exactly, your copy is identical to what was anchored.
